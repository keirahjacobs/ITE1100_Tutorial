# ITE1100_Tutorial_Keirah 
# Reason for Repository
This repository was created for an assignment with the task of getting a better understand for the platform for future use 
# Steps taken 
1. Installed Git onto personal laptop and created a GitHub account 
2. Created a new local repository using Git bash
3. Added a sample text file (Keirah_jacobs.txt) that displays name 
4. Committed changes using (git commit -m "Add your_text_file.txt to the repository")
5. Pushed new Branch to GitHub Repository using (git push -u origin <branch-name>) 
6. Created a pull request on the GitHub repository and assigned a reviewer 
7. Once the review is approved by collaborator, the new branch is merged into the main (master) branch
